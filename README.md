# Risultati dei modelli · previsione della potenza fotovoltaica

Dashboard interattiva con i risultati dei modelli sviluppati per la tesi triennale
(regressione, LSTM endogena, LSTM esogena): metriche, confronti con i riferimenti ingenui,
esploratore dei periodi di test e grafici originali.

Apri la dashboard: **https://marcodezan.github.io/Tesi-triennale/**

La pagina funziona interamente nel browser; i dati sono già inclusi in `data.js`.
